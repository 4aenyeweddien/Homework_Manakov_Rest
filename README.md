# Домашняя работа по блоку 30.1

## Описание:

Домашняя работа по блоку 30.1. Вьюсеты и дженерики. Создан новый Django-проект и подключен DRF. Реализованы приложения 
users и materials. В приложении materials реализованы модели Course и Lesson. Для модели course релизованы вьюсеты. Для
модели lessons дженерики. Реализованы эндпоинты для редактирования профилей любого пользователя.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/username/myblog.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
