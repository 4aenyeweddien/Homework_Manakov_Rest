# Домашняя работа по блоку 31

## Описание:

Домашняя работа по блоку 31. Права доступа в DRF. Реализован CRUD для пользователя. Заведена группа модераторов и описаны
права работы с любыми уроками и курсами. Описаны права доступа для объектов, пользователи могут видеть, редактировать 
и удалять только свои курсы и уроки.

```

```

```
pip install -r requirements.txt
```
